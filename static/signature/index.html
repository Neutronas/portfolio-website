Add to Gmail

  1. Click Copy above (or select the signature with the mouse and press Ctrl+C).
  2. Gmail → ⚙ Settings → See all settings → General → Signature → Create new.
  3. Click in the signature box and press Ctrl+V.
  4. Under Signature defaults, pick it for new emails and replies.
  5. Scroll down and click Save Changes.
